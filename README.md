# 🍕 Pizza Sales Analysis using SQL

## 📊 Project Overview

This project analyzes pizza sales data using SQL to extract meaningful business insights such as revenue trends, top-selling products, and customer behavior.

## 🛠 Tools Used

* SQL (MySQL / PostgreSQL)

## 📈 Key Analysis Performed

* Total Revenue Calculation
* Total Orders and Quantity Sold
* Top 5 Best-Selling Pizzas
* Sales by Category and Size
* Peak Order Time Analysis
* Daily and Monthly Trends

## 🧠 Sample Queries

* Revenue Calculation using SUM()
* Order Count using COUNT(DISTINCT order_id)
* GROUP BY for category-wise analysis
* ORDER BY for top products

## 📁 Files Included

* pizza_sales.sql
* dataset.csv

## 🎯 Objective

To analyze sales data and generate insights that help improve business decisions.
